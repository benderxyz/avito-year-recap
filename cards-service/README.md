# Cards Service

Service responsible for building recap scenarios and generating cards for the frontend.

Planned areas:

- `internal/cards` - recap scenario and card assembly.
- `internal/llm` - neural network integration.
- `internal/prompts` - prompt templates.
- `internal/safety` - filtering sensitive data before personal and share cards.
- `internal/clients` - clients for analytics-service and user-service.
- `internal/api` - frontend-facing API handlers.
