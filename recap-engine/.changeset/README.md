# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that works with multi-package repos to help version and publish code. You can find the full documentation for it [in our repository](https://github.com/changesets/changesets).

We have a quick list of common next steps to get you started writing changesets from this folder:

1. Make some changes, then run `pnpm changeset` in `recap-engine`
2. Commit the generated markdown file along with your code
3. After merge to `main`, CI opens a Version Packages PR (or run `pnpm run version` + `pnpm release` locally)
