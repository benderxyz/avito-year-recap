# Документация Recap Engine

Сайт документации построен на [Docusaurus](https://docusaurus.io/).

Команды выполняются из директории `recap-engine`:

```bash
pnpm install
pnpm docs:start
```

Production-сборка:

```bash
pnpm docs:build
```

Страницы документации находятся в `docs/docs`, конфигурация навигации — в `sidebars.ts`.
