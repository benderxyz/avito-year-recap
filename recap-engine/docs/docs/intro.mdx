# Recap Engine

Recap Engine помогает собрать **интерактивную историю с итогами года** — как Stories в Instagram, но с вашими данными: числами, текстами, бейджами и кнопками.

Пользователь листает полноэкранные **сцены** (экраны): приветствие → статистика → инсайты → финал. Библиотека берёт на себя анимации, свайпы, клавиатурную навигацию и progress bar.

## Из чего состоит

| Пакет | Что делает |
|-------|------------|
| [`@recap-engine/core`](./core/recap-payload) | Описывает **структуру данных** и **сцены**, готовит JSON с сервера, форматирует числа, задаёт тему |
| [`@recap-engine/react`](./react/recap) | Рисует **компонент `<Recap>`** — плеер, который показывает сцены пользователю |

Core можно использовать без React (например, на сервере). React всегда опирается на core.

## Три вещи, которые вы передаёте в `<Recap>`

```tsx
<Recap theme={theme} data={data} scenes={scenes} />
```

| Prop | Простыми словами |
|------|------------------|
| `data` | **Данные** — имя пользователя, метрики, всё, что нужно показать на экранах |
| `scenes` | **Сценарий** — список экранов: что на каждом показать и в каком порядке |
| `theme` | **Оформление** — цвета, шрифты (результат `createTheme()`) |

Откуда берутся `data` и `scenes` — два варианта, подробнее в [Архитектуре](./getting-started/architecture):

1. **С сервера** — API отдаёт JSON, вы вызываете `prepareRecap(payload)`.
2. **В коде** — вы сами описываете сцены через `defineScenes([...])`.

## Установка

```bash
pnpm add @recap-engine/core @recap-engine/react react react-dom
```

Подключите стили — без них компонент не будет выглядеть правильно:

```tsx
import '@recap-engine/react/styles.css';
```

Нужен React 19 (peer dependency).
