# Компонент Recap

`<Recap>` — **главный компонент библиотеки**. Это полноэкранный плеер, который показывает ваши сцены, рисует progress bar и обрабатывает навигацию.

## Минимальный вызов

```tsx
import { createTheme, defineScenes, ESceneType } from '@recap-engine/react';
import { Recap } from '@recap-engine/react';
import '@recap-engine/react/styles.css';

<Recap theme={createTheme()} data={data} scenes={scenes} />
```

Три обязательных prop:

| Prop | Что передать |
|------|--------------|
| `theme` | Результат `createTheme()` |
| `data` | Ваши данные (объект с метриками, именем и т.д.) |
| `scenes` | Массив экранов из `defineScenes()` или из `prepareRecap()` |

## С данными с сервера

```tsx
const prepared = prepareRecap(payload);

<Recap
  {...prepared}
  theme={createTheme()}
  locale={prepared.locale}
/>
```

Spread `{...prepared}` передаёт `data`, `scenes`, `badges`.

## Что включено из коробки

- Progress bar (точки или полоска)
- Свайпы, стрелки ← →, кнопки навигации
- Tap-зоны слева/справа (как в stories) — опционально через `tapNav`
- Удержание для паузы autoplay — опционально через `holdToPause`
- Анимации переходов и count-up на числах
- Autoplay с паузой на анимации числа
- Поддержка `prefers-reduced-motion`

## Частые props

| Prop | Default | Описание |
|------|---------|----------|
| `autoplay` | выкл. | Автолистание (`true` или `{ delayMs: 5000 }`) |
| `loop` | `false` | Зациклить после последней сцены |
| `gestures` | `true` | Свайпы |
| `tapNav` | `false` | Тап по левой/правой части экрана для prev/next |
| `holdToPause` | `false` | Пауза autoplay при удержании указателя (stories-style) |
| `initialSceneId` | первая сцена | Стартовый экран по `id` |
| `locale` | `'ru-RU'` | Локаль для чисел и валют |
| `badges` | `[]` | Бейджи для achievement-сцен |
| `reducedMotion` | системная настройка | Принудительно упростить анимации |
| `className` | — | CSS-класс на корневой элемент |
| `slots` | — | Заменить фон, progress bar или footer |
| `onEvent` | — | Колбэк при смене сцены, кликах, завершении |

## slots — замена частей UI

```tsx
<Recap
  theme={theme}
  data={data}
  scenes={scenes}
  slots={{
    header: <MyProgressBar />,   // вместо стандартного progress
    background: <MyBackground />,
  }}
/>
```

## Stories-style жесты

Поведение как в Telegram/Instagram stories — включается отдельными props:

```tsx
<Recap
  theme={theme}
  data={data}
  scenes={scenes}
  autoplay
  holdToPause   // удержание — пауза, отпускание — продолжение
  tapNav        // тап слева = prev, справа = next
/>
```

`tapNav` можно настроить ширину зон:

```tsx
<Recap
  {...prepared}
  tapNav={{ leftRatio: 0.25, rightRatio: 0.25 }}
/>
```

По умолчанию каждая зона занимает ~33% ширины экрана. Центральная область не реагирует на тап. Клики по кнопкам и progress bar не перехватываются.

`holdToPause` работает только при включённом `autoplay` и синхронизирован с progress bar.
